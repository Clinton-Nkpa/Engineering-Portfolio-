# Clinton Nkpa Engineering Portfolio

A self-contained static portfolio website.

## Files
- index.html — site content
- style.css — responsive styling
- script.js — navigation behaviour

## Run locally
Open `index.html` in a browser.

## Deploy
The site can be deployed directly to any static hosting service. No build step or framework is required.

## Content basis
The project descriptions are based on the current engineering CVs and the project history developed in the portfolio conversation. Future project case studies can be expanded with photographs, architecture diagrams, GitHub links, test results and source-code excerpts.
