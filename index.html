04 / LINUX • SYSTEMS OPTIMISATION

SteamOS Memory Leak Mitigation

Investigated progressive memory consumption during high-fidelity Windows applications running through Proton and developed repeatable Linux-side mitigation workflows.

  • SteamOS / Arch Linux immutable system constraints
  • Expanded swap allocation to handle memory spikes
  • Page-cache flushing through Bash and kernel interfaces
  • Raised vm.max_map_count and persisted the configuration
  • Separated kernel-level workarounds from leaks originating inside the Proton runtime
